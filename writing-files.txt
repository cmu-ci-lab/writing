# Files distributed from this repository into every templates/<name>/ directory
# by scripts/sync-templates. One path per line, relative to the repository root.
# Blank lines and lines starting with `#' are ignored.
#
# Only files named here are ever copied, so nothing else in this repository can
# reach a published template repo. A template's own files -- its .tex, .sty,
# .bib, figures/, and config.mk -- are never listed here and never touched.
#
# A venue kit file counts as the template's own when the venue does not ship it
# on CTAN, since a template that did not carry it would not build: templates/
# paper-cvpr/ owns cvpr.sty and ieeenat_fullname.bst on those grounds, and
# templates/paper-eccv/ owns eccv.sty and splncs04nat.bst on the same ones.
# A file TeX Live also provides still counts as the template's own when the two
# copies are not the same file: templates/paper-eccv/ owns llncs.cls, since the
# ECCV kit ships v2.22 against TeX Live's v2.24 and v2.24 adds the credits
# environment and \discintname, and templates/paper-tog/ owns acmart.cls and
# ACM-Reference-Format.bst, since the current kit is v2.16 against the v2.03
# this machine's TeX Live carries. Whichever way the pin points, the template
# carries the version its venue expects and builds against that one.
#
# Adding or removing a line here is the whole interface: the next sync copies
# what was added, and deletes from each template what was removed, because each
# template records the manifest it was last synced against in .writing-files.
